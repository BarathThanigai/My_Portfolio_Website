# Personal Portfolio Website

A modern, responsive developer portfolio built to showcase my projects, technical skills, experience, certifications, and achievements. The website serves as a central hub for my software engineering, artificial intelligence, machine learning, data science, and cybersecurity projects while providing an easy way for recruiters and collaborators to connect with me.

## Features

* Responsive and modern user interface
* Dark and light theme support
* Interactive project showcase with GitHub links
* Categorized technical skills section
* Professional experience and certifications
* Animated UI powered by Framer Motion
* Contact form integrated with a custom FastAPI backend
* Resume download functionality
* Smooth scrolling and responsive navigation

## Tech Stack

* React
* Vite
* JavaScript
* Tailwind CSS
* Framer Motion
* React Icons
